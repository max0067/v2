🚀 COMMENT TRANSFÉRER SUR VOTRE SERVEUR :

Option 1 - Via cPanel File Manager (⭐ RECOMMANDÉ) :
   1. Téléchargez : veille_juridique.tar.gz
   2. Connectez-vous à cPanel sur dusselle.fr
   3. File Manager → votre répertoire app (voir "Application Root" dans Setup Python App)
   4. Upload → veille_juridique.tar.gz
   5. Clic droit → Extract

Option 2 - Via Git :
   Sur votre serveur :
   git clone <url-repo> temp
   cd temp
   git checkout claude/legal-rss-monitoring-app-011CUqNqkGBZNE7ayYqntiii
   cp -r veille_juridique/* ~/votre-app-directory/

Option 3 - Via SCP/SFTP :
   scp veille_juridique.tar.gz wrbh3411@dusselle.fr:~/votre-app-directory/

📝 APRÈS LE TRANSFERT, SUR VOTRE SERVEUR :

cd ~/votre-app-directory    # Remplacez par le bon chemin
source venv/bin/activate     # Activer l'environnement virtuel
pip install -r requirements.txt
python app.py --init         # Initialiser la base de données
python app.py --sample       # Ajouter des flux d'exemple

Puis dans cPanel → Setup Python App → Restart
